# 公司法英语学习室

本地优先的中英双语《中华人民共和国公司法》学习工具。

当前版本包括：

- 2023年修订《公司法》中文全文，共266条；
- 中英文条文对照界面及英文PDF本机导入；
- 按章节和知识点筛选；
- 中英文全文检索；
- 全15章的“章节框架—核心概念—核心表达—重点条文”学习路径；
- 中英文逐词悬停对应，以及 Chrome/Edge 浏览器本机翻译模型增强；
- 可调宽度、全屏阅读、字体缩放、文字高亮、加粗、划线和批注；
- 收藏、笔记、批注跳转、学习进度及本地备份。

请参阅 `LOCAL-USE.md`。司法解释与法考练习模块将在后续资料补充后加入。

## 静态网页与 Netlify 部署

项目可以导出为只包含 HTML、CSS、JavaScript 和静态资源的网页：

```bash
npm install
npm run build:static
```

构建结果位于 `out` 文件夹。手动部署时，将整个 `out` 文件夹拖入
Netlify；连接 GitHub 仓库部署时，仓库根目录的 `netlify.toml` 会让
Netlify 自动执行静态构建并发布 `out`。

不要直接双击 `out/index.html` 作为日常本地启动方式；浏览器对 `file://`
页面有额外限制。在 Windows 上双击 `start-static.bat` 即可用本地静态服务
打开与 Netlify 相同的效果。

静态构建会从项目根目录的 `公司法英文版（威科先行译版）.pdf` 提取 266 条
默认英文译文。访问者首次打开即可使用，也可以在页面中选择自己的 PDF
替换；替换后的内容只保存在访问者自己的浏览器中。

将仓库或网站设为公开前，请确认你拥有该默认英文译文及 PDF 的公开传播
许可；否则应继续使用私有仓库，或移除内置译文后仅保留用户本机导入功能。

静态版的学习进度、收藏、笔记、批注和用户导入的英文 PDF 仍只保存在
访问者自己的浏览器中，不需要在线数据库。
